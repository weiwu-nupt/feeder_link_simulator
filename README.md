# Qt 星座拓扑仿真桌面原型

该程序使用 Qt for Python（PySide6，与 PyQt 使用同一套 Qt API）和内嵌 Cesium，实现参数配置、后台逐帧计算、分块数据传递以及二维/三维显示。

## 运行

在项目根目录，用启动软件的同一 Python 环境安装依赖并运行。当前已在 Python 3.13 上验证。

```powershell
python -m pip install --upgrade -r requirements.txt
python main.py
```

`requirements.txt` 包含全软件的 Python 依赖，PySide6 会安装对应的 Qt WebEngine 组件。
安装命令会检查当前环境，补装缺失项，并把清单中的依赖升级到满足版本条件的最新兼容版本。
“链路仿真”依次提供信道仿真、模型库、全链路仿真。软件启动进度窗口会预先加载依赖并初始化全部链路仿真页面，完成后才显示主界面；默认进入星座仿真，切换链路仿真时直接显示已准备好的页面。

## 代码结构

- `main.py`：程序启动入口，不承载业务实现。
- `main_window.py`：主窗口、界面状态和仿真交互编排。
- `models.py`：场景与仿真配置数据模型。
- `result_store.py`：`.hysim` 压缩写入、索引和随机回读。
- `web_bridge.py`：Python 与 Cesium 间的 Qt WebChannel 接口。
- `viewer.html`：Cesium地图渲染和地图内交互。

Cesium和OpenStreetMap底图默认从互联网加载。打开程序后应先看到地球，再设置参数并点击“开始仿真”。

## 当前功能

- 第8章界面框架：采用顶部命令区、左侧工程树、中部多标签视图区、右侧属性面板和底部状态栏五区布局。菜单完整划分为工程、场景、仿真、视图、数据与帮助，常用命令带图标进入工具栏；程序使用卫星图标和Windows深色标题栏。
- 工程树：严格按链路层与组网层组织，每层继续划分模型库、场景、仿真任务和结果。选择星座、信关站、拓扑或动态显示节点时，右侧属性面板联动展开对应分类；星座与信关站配置归入“新建场景”。
- 布局与状态：工程树和属性面板支持带缓动的折叠/展开，窗口变窄时自动折叠并在空间恢复后展开；布局可保存、加载和恢复默认值。状态栏分区显示运行状态、消息、耗时、计算进度、传输进度、CPU/内存和告警数量。
- 属性抽屉：右侧默认折叠为48像素宽的竖向条状标签，标签文字竖排显示“星座时间、信关站、链路规则、显示控制”；点击标签后从右侧平滑展开对应内容，再次点击当前标签收回。开始生成仿真数据时抽屉自动收起，并锁定会改变计算输入的星座、站址、时间、拓扑和门限参数；播放倍速、时间轴、显示范围和图层开关继续可用。
- 对象信息：点击卫星可查看当前时刻的位置、轨道面/星位、同轨与异轨邻星、可见信关站；点击信关站可查看站址、GSL约束、当前可见卫星数量和ID。信息随仿真帧同步刷新。
- 态势大屏：地图左下角实时显示可见卫星数、GSL数、有效信关站数、平均仰角、各站可见数量，以及按仰角排序的可见卫星摘要。主窗口采用深色数据大屏配色。
- 数据导出：选择“数据 → 导出当前结果与时序汇总”可导出场景配置JSON、已计算时间点的轻量时序汇总CSV，以及当前时刻的卫星、ISL、GSL和信关站可见性明细CSV。容量、时延、EVM、BER、SNR和波形需等待相应链路/调度模块产生真实数据后再加入导出。

- Walker星座：卫星数、轨道面、相位、半长轴对应高度、倾角、偏心率、近地点幅角。默认圆轨道固定使用 `e=0.0000001`；选择椭圆轨道后可编辑偏心率。
- Walker构型：Delta将RAAN铺设在360°范围；Star将RAAN铺设在180°范围，适合配合近极轨、首尾轨道缝隙和运动方向演示。
- TLE导入：支持Hypatia头部格式和常见的二行/三行TLE；轨道面数用于建立规则候选ISL。
- 仿真：时长、步进和0.5至20倍播放。
- 地面站：预设城市及可编辑经纬度、高度、最小仰角和最大GSL斜距。
- ISL：同轨环、相邻轨道面同编号候选、异轨高纬度门限、最大距离和地球遮挡判断。
- ISL构型：可选择4-ISL规则网格（同轨前后2条、异轨左右2条）或3-ISL固定砖墙（同轨前后2条、按奇偶交错保留1条异轨链路）；两种构型均实时应用高纬度门限。
- 轨道缝隙：可指定某轨道面与下一轨道面之间禁止建立异轨ISL（最后一面之后循环到第1面）。地图以红色虚线显示本来满足几何条件、但因缝隙被禁用的候选链路；这些红线不进入有效拓扑。
- 运动方向：根据前后显示帧的三维位置求局部运动方向，在卫星当前位置附近沿轨迹切线绘制短箭头；卫星本体同步使用方向颜色。首帧尚无前一时刻的位置，从第二个显示帧开始出现箭头。
- 编号标签：放大地图后显示 `P轨道面-S轨内编号 (#全局卫星ID)`，例如 `P20-S37 (#1936)`；可在“显示控制”分类随时开关，无需重新生成数据。
- 显示范围：可指定一个中心轨道面，只向Cesium发送其邻近3个、5个或全部轨道面；轨道面编号从1开始并按首尾循环取邻轨。程序保留最近一帧的完整结果，修改显示范围或图层开关无需重新仿真。
- 交互式时间轴：位于地图下方，可播放、暂停并跳到仿真区间内任意过去或未来时刻；跳转时仅计算目标帧。播放倍速运行中可调。界面同时显示相对仿真时间和TLE/Walker历元对应的UTC绝对时间。
- 执行分为两个阶段：先点击“生成仿真数据”，生成或读取TLE、建立轨道传播对象、生成ISL候选和时间轴；准备完成后按钮变为“播放”，才开始逐时间点计算卫星位置、有效ISL和GSL。播放、暂停、继续和重新播放共用同一按钮；“结束”用于终止并恢复初始状态。
- 图层：卫星、同轨ISL、异轨ISL和GSL独立控制。
- 显示：Cesium 2D/3D切换，后台计算进度和当前帧分块传递进度。

## 模型边界

导入TLE时，当前版本根据用户填写的轨道面数，将TLE中的卫星按文件顺序均分到各轨道面。对于不规则星座，后续应增加按RAAN聚类和动态异轨匹配。跨轨链路当前使用相邻轨道面同序号卫星作为候选，并实时检查纬度、距离和地球遮挡。

Walker界面中的高度是半长轴减去地球半径。椭圆轨道的近地点高度为
`(地球半径 + 输入高度) × (1 - 偏心率) - 地球半径`。程序要求近地点至少为100 km，参数不满足时会在计算前给出所需的最低高度。

## 信道实测数据与底噪

信道页签顺序为功放、滤波器、混频器、ADC/DAC、底噪模型。滤波器和混频器分别提供“参数建模”和“实测数据建模与导出”。在实测页浏览数据文件，点击“建立模型并预览”，再保存到模型库或导出统一模型文件。

- 滤波器 MAT/NPZ：提供 `h` 冲激响应，或 `b`/`a` 系数、`sos` 系数；可附带 `fs`（Hz），缺省使用页面当前采样率。CSV/TXT 支持单列冲激响应，或三列“频率 Hz、增益 dB、相位 deg”。频响数据按当前采样率插值，测量范围外响应为零，以实信号共轭对称频谱生成 4096 点 FIR；需要保留复数冲激响应时使用 MAT/NPZ 的 `h`。
- 混频器 CSV/TXT：两列“频偏 Hz、相噪 dBc/Hz”；MAT 提供等长的 `offsets` 和 `levels` 数组。频偏须为正、无重复且低于当前采样率的一半。表格允许一行表头。
- 底噪：独立复高斯白噪声模型，以单位满量程功率为参考，密度单位为 dBFS/Hz，总功率为 `10^(密度/10) × fs`。可预览频谱，通过模型库保存和加载，并在全链路中添加“底噪模型”节点使用；链路按输入采样率生成噪声，随机种子固定时可复现。
